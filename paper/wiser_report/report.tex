\section*{Abstract}
Physics-informed neural networks learn smooth, slow variations quickly and sharp, fast
ones slowly. A quantum circuit that re-uploads its input can only produce a fixed,
predictable set of frequencies. We turned that into a design rule, SMCD: read the
frequencies a PDE's solution needs from the equation, then build the circuit whose
frequency set covers them, with no architecture search. Our model mixes eight copies of
the designed circuit through a linear output layer.

We applied it to a real planning problem: waterlogging of farmland between two rivers,
fed by six leaking irrigation canals. Predictions were committed to git before training,
the model was tested on seeds never used in development, and a script issued every
verdict. The model met all five predictions. It reproduces the water table to
0.09\% error, 18$\times$ more accurately than a classical network of the same size and
9.9$\times$ more accurately than the same circuit with random frequencies, and it
places the waterlogged stretch of the field to within 1\,m (714\,m vs.\ 713\,m exact).
It also answers the planner's question directly: lining the canals to cut seepage by
\GWDryCut\% dries the whole field. On the Poisson benchmark the designed circuit beats
its random-frequency twin by 236$\times$ and a Fourier-feature network by three orders
of magnitude.

\section{The problem: neural networks learn slow waves first}
A standard physics-informed neural network (PINN) fits a smooth solution quickly and
struggles with fine detail. This is \emph{spectral bias}: the network's learning speed
falls with frequency. Below, a classical network halves its error on the slow $\sin\pi x$
part of a Poisson solution within \StairPi{} steps, and needs \StairFastLo--\StairFastHi{}
steps for the fast $\sin15\pi x$ part.

\begin{center}
  \includegraphics[width=0.62\linewidth]{staircase}
\end{center}

A re-uploading quantum circuit behaves differently. Its output is a Fourier series whose
frequencies are fixed by how the input is encoded, so they can be chosen in advance.

\textbf{Example.} Poisson's solution $\sin\pi x + 0.3\sin15\pi x$ needs the frequencies
$\pi$ and $15\pi$. SMCD picks encoding scalings $\pi\cdot\{1,3,9,27\}$ on one qubit with
four layers; the circuit can then produce every multiple of $\pi$ up to $40\pi$, which
covers both. No search, and the design is checkable before training.

Why eight copies: in a single circuit every wave amplitude depends on the same few
angles, so improving one frequency disturbs another. Separate copies mixed by a linear
head give the model an independent handle on each amplitude (Section~\ref{sec:why}).

\section{Why it works}\label{sec:why}
\subsection*{The designed frequencies matter}
Same circuit, same size, same training; only the frequencies differ. With the designed
frequencies the error is 9.9$\times$ lower on the farmland problem and 236$\times$ lower on
Poisson, on every held-out seed. The effect already shows in a single copy: on the heat
equation the designed circuit beats its random twin on every seed (95\% interval
\HeatCILo--\HeatCIHi$\times$).
\begin{center}
  \includegraphics[width=\linewidth]{headline_design_vs_random}
\end{center}

\subsection*{Eight copies, not one}
We chose the number of copies and the learning rate on the tuning seeds. One copy
(14 parameters) cannot fit Poisson at either learning rate; eight copies reach 0.3\%.
The same holds on held-out data: on the farmland problem a single copy scores 53\% error
against 0.09\% for eight.
\begin{center}
  \includegraphics[width=\linewidth]{headline_v2_lab}
\end{center}

The per-frequency error shows the mechanism in a single copy. It removes the hard
$15\pi$ error early, then loses the easy $\pi$ component: every amplitude is tied to the
same ten angles, and the loss weights the $15\pi$ mode 225 times more, so fixing one
costs the other. Eight copies with a linear head set the amplitudes independently.
\begin{center}
  \includegraphics[width=\linewidth]{xai_spectral_error_poisson}
\end{center}

\section*{Summary}
\begin{itemize}
  \item \textbf{A design rule that works as specified.} SMCD reads the needed frequencies
    from the equation and builds a circuit that produces exactly those, with no search.
  \item \textbf{Accurate on a real problem.} On waterlogged farmland the model reaches
    0.09\% error, 18$\times$ better than a classical network of the same size, and gets
    the waterlogged length right to 1\,m.
  \item \textbf{The design is the reason.} The same circuit with random frequencies is
    9.9$\times$ worse on farmland and 236$\times$ worse on Poisson.
  \item \textbf{Scored strictly.} Predictions locked on GitHub before the runs, held-out
    seeds, and a script issuing every verdict: 5 of 5 on farmland.
  \item \textbf{Next.} Run the circuits on quantum hardware (everything here is
    simulated), and close the gap to the frequency-matched classical model on Poisson.
\end{itemize}
