\section{Reproducibility}
\label{sec:repro}

The code, every run's metrics and instrument records, and the scripts that turn them into
every figure, table and verdict are in the project repository; no figure reloads a
trained model. All runs used one machine (NVIDIA RTX 4090 Laptop GPU, 32 CPU cores) with
Python 3.12, PyTorch 2.11 (CUDA 12.8), PennyLane 0.45, NumPy 2.4 and SciPy 1.18, pinned by
\texttt{uv}. A single integer seeds Python, NumPy and PyTorch with deterministic
algorithms, so two runs at the same seed on the same device give bit-identical metrics.
Seeds: six-problem matrix 0--4; coverage and barren-plateau sweeps 0--2; model selection
for circuit copies 0--2; held-out evaluation of the eight-copy circuit and all groundwater
models 10--14. \texttt{tasks.py test} runs the test suite (about 4 minutes on CPU),
\texttt{tasks.py figures} redraws every figure from the committed runs (about 30\,s),
\texttt{tasks.py repro-quick} trains all problems and families at reduced size (about 9
minutes on CPU), and retraining all 327 recorded runs from scratch takes about 130 hours
on the machine above.
