\section{Introduction}
\label{sec:intro}

A classical physics-informed neural network (PINN) learns low-frequency solution
components fast and high-frequency components slowly --- spectral bias --- because its
neural tangent kernel (NTK) eigenspectrum decays with Fourier-mode index. Separately, a
data-re-uploading variational quantum circuit realises a truncated Fourier series whose
frequency set is determined exactly by the eigenvalues of its data-encoding Hamiltonians
\citep{schuld2021effect}. Prior hybrid quantum PINN work
\citep{hybrid_qpinn_mlst,hybrid_when_where_2606,qpinn_maxwell_2506,cq_hybrid_arch_2511}
reports accuracy on hand-picked circuit sizes, without a principled way to choose the
circuit \emph{given} the PDE.

This paper joins the two facts. Given a PDE, the target spectral support is computed
from the operator's Fourier symbol and the forcing and boundary data; the circuit's
encoding scalings, re-uploading depth, qubit count and entangler then follow by formula
so that its frequency set covers that support. We call this Spectrum-Matched Circuit
Design (SMCD, Section~\ref{sec:methodology}). The hybrid model mixes $K$ copies of the
designed circuit through a linear head: every copy has the designed frequencies, and the
head sets their amplitudes independently.

A design rule is only useful if it can be tested, so the project is built around
measurement. Six explainable-AI instruments run at the same checkpoints on matched
classical and hybrid models (Section~\ref{sec:xai}), so any difference can be traced to
the quantum layer. Every claim about the method was written down with a numeric
threshold and committed to git before the runs that test it, and a script issues every
verdict.

\paragraph{Contributions.}
\begin{enumerate}
\item \textbf{SMCD, a constructive map from PDE to circuit}
  (Section~\ref{sec:methodology}): four propositions and an algorithm that output the
  encoding scalings, depth, qubit count and entangler deterministically, with a design
  card that can be checked before training.
\item \textbf{A hybrid NTK decomposition} for models with disjoint classical and quantum
  parameters, $\Theta_{\mathrm{hyb}}=\Theta_{\mathrm{cl}}+\Theta_q$, with no cross term
  (Section~\ref{sec:prop4}).
\item \textbf{Circuit copies}, a model family in which $K$ copies of the designed
  circuit share its frequency set but have independent amplitudes
  (Section~\ref{sec:copies}).
\item \textbf{An explainable-AI protocol for hybrid PINNs}: six instruments with
  published metric definitions, run identically on every model family
  (Section~\ref{sec:xai}).
\item \textbf{Evidence} from seven model families on six PDE instances and one applied
  problem, groundwater under irrigated farmland (Sections~\ref{sec:results}--\ref{sec:groundwater}).
\end{enumerate}

\paragraph{Findings in brief.} The circuit realises exactly the frequencies SMCD designs.
Designed frequencies beat random ones of the same size wherever the circuit learns the
solution: heat, Poisson and groundwater. One copy is not enough on problems that mix a
slow and a fast wave, and the instruments show why; eight copies fix it, reaching 0.09\%
error on the groundwater problem, $18\times$ better than a classical network of the same
size. The method does not beat every classical model: on Poisson a classical model
handed the same frequencies stays ahead, on the smoothing heat equation no model beats a
plain MLP (as SMCD predicts), and at high Helmholtz wavenumbers every model fails.
